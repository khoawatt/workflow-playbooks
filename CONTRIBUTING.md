# Contributing to Workflow Playbooks

Thank you for your interest in contributing to `workflow-playbooks`!

---

## Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/khoawatt/workflow-playbooks.git
   cd workflow-playbooks
   ```

2. **Conventions**:
   * All Markdown filenames and folders follow `lowercase-kebab-case.md` — see [meta/naming-conventions.md](meta/naming-conventions.md).
   * Start from [templates/playbook-template.md](templates/playbook-template.md) when adding a new document.
   * Add one row to [docs/index.md](docs/index.md) with category, purpose, and when to use it.

---

## Pull Request Guidelines

1. **Keep it focused**: One playbook or category per PR.
2. **Naming convention**: `lowercase-kebab-case.md` for all docs.
3. **Index entry required**: Any new document must be listed in `docs/index.md`.
4. **No secrets**: Never commit `.env`, tokens, or private data.
